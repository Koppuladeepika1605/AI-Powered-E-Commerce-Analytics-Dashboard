## 1. What is Data Cleaning?

Data cleaning is the process of identifying and correcting missing, incorrect, inconsistent, duplicate, or improperly formatted data so that the dataset becomes reliable for analysis.

* **Numerical Library:** NumPy

* **Output:** Cleaned CSV / Analytics-ready CSV

# 12. Check Numeric Columns

For a new dataset, identify columns that should contain numbers.

Example:

```python
print(df['Qty'].dtype)
```

Convert when necessary:

```python
df['Qty'] = pd.to_numeric(df['Qty'], errors='coerce')
```

For amount:

```python
df['Amount'] = pd.to_numeric(df['Amount'], errors='coerce')
```

### Why `errors='coerce'`?

Invalid values become missing values instead of crashing the entire conversion.

Then we can inspect those missing values.

# 17. Handle Missing Values

First:

```python
print(df.isnull().sum())
```

Then decide what to do **based on the meaning of the column**.

### Example — categorical field

My project:

```text
Courier_Status → Unassigned
```

Conceptually:

```python
df['Courier_Status'] = (
    df['Courier_Status']
    .fillna('Unassigned')
)
```

### Example — currency

My project used:

```text
Currency → INR
```

when the currency was missing.

### Example — numeric amount

My project used:

```python
df['Gross_Amount'] = df['Recorded_Amount'].fillna(0.0)
```

### VERY IMPORTANT

Do not say:

> “I replace all missing values with zero.”

Instead say:

> “I handled missing values according to the business meaning of each field.”

# 22. Realized Revenue

This is one of the most important project-specific transformations.

The project distinguishes:

```text
Gross_Amount
```

from:

```text
Realized_Revenue
```

The project defines certain statuses as non-realized:

```python
non_realized_statuses = {
    'Cancelled',
    'Shipped - Returned to Seller',
    'Shipped - Returning to Seller',
    'Shipped - Rejected by Buyer',
    'Shipped - Lost in Transit',
    'Shipped - Damaged',
    'Shipping'
}
```

Then the condition is:

```python
condition = (
    ~df['Status'].isin(non_realized_statuses)
    & (df['Qty'] > 0)
    & (df['Gross_Amount'] > 0)
)
```

Then:

```python
df['Realized_Revenue'] = np.where(
    condition,
    df['Gross_Amount'],
    0.0
)
```

And:

```python
df['Is_Realized'] = condition
```

### Interview answer

> “I created a Realized Revenue field using business rules. Transactions with non-realized statuses were excluded, and I also required positive quantity and positive gross amount.”

### IMPORTANT

This is **specific to my Amazon project**.

If an interviewer gives you another dataset, don't automatically use these statuses.

Ask/understand:

> “What does the business consider a realized sale?”

Then create the appropriate rule.

# ⭐ 31. THE MOST IMPORTANT THING TO MEMORIZE

Don't memorize 500 lines of Python.

Memorize this:

> **LOAD → INSPECT → CLEAN → STANDARDIZE → HANDLE MISSING VALUES → VALIDATE → TRANSFORM → SAVE → VERIFY**

And remember **WHY** you do each step.

If the interviewer gives you a new dataset, your first move should **not** be to start deleting columns.

Your first move should be:

```python
df = pd.read_csv("new_dataset.csv")

print(df.shape)
print(df.head())
print(df.columns)
print(df.dtypes)
print(df.isnull().sum())
print(df.duplicated().sum())
```

Then you decide what actually needs cleaning.

That is the difference between **memorizing a cleaning script** and being able to **actually perform data cleaning in an interview**.
